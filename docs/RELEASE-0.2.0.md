# 养鱼 0.2.0

养鱼是 DeepSeek Harness 的多角色陪伴插件。可以创建不同的伙伴，使用可选人设和各自的记忆库，并通过“出游”连接 QQ 或微信机器人通道。

## 本版功能

- 原生侧栏入口、角色管理、持久会话绑定及人设导入。
- 每个角色独立的记忆库，可查看、搜索、修改、删除和导出。
- 出游页面显示真实登录二维码，支持刷新、过期提示和连接状态。
- 连接后处理允许范围内的新文字私聊，使用当前角色的人设和记忆工具。
- 可暂停、恢复或解除连接；授权不包含在角色导出文件中。

## 安装条件

需要 Node.js 22.12.0 或以上以及兼容的 DSH。当前真实验证宿主为 DSH 0.2.1-rc.5。聊天沿用宿主的模型和额度，插件本身不提供模型服务。

下载本版本的 `.tgz` 安装包后，使用宿主的插件管理器，或在终端执行：

```powershell
dsh plugin --profile <实际使用的profile> add "C:\path\to\dsh-yangyu-0.2.0.tgz"
```

安装到桌面端时应使用桌面应用实际采用的 profile，不能直接套用 `web`。安装后重启 DSH。

## 已知范围

- QQ 需要已经安装并配置的本机 NapCat；本版没有完整的 NapCat 安装向导。
- 微信使用 ClawBot / iLink 机器人通道，不读取个人微信历史或全部好友。
- 当前不接入群聊、图片、语音、文件或视频。
- 同一角色的长期记忆会在该角色的会话之间共享，包括允许名单内的联系人；不同联系人的长期记忆尚未拆分。
- 不保证每轮聊天都自动提取记忆；可在记忆库查看或纠正。
- 本地授权文件尚未提供独立密码加密，不要上传授权、角色私人记忆或用户配置。

## 验证

80 项自动测试通过。真实 DSH 已验证角色记忆基础流程、出游页面、微信出码及刷新，以及复用已有 QQ 登录会话的一次私聊回复。全新 QQ 扫码和微信登录后的消息往返仍待本人验证。详情见 [VALIDATION.md](VALIDATION.md)。
